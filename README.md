# Архив сайтов

Сайт-архив для статических сайтов. Загружаете HTML-файл (или ZIP-архив с сайтом целиком — со стилями, картинками и скриптами), он сохраняется на сервере и становится доступен по постоянной ссылке вида `https://ваш-домен/s/abc123xyz9/`.

## Возможности

- Загрузка перетаскиванием или через выбор файла: `.html`, `.htm`, `.zip`.
- Для ZIP точкой входа становится `index.html` (или первый HTML-файл); общая корневая папка внутри архива убирается автоматически.
- Название берётся из `<title>`, если не указать своё; можно добавить описание.
- Список всех сайтов с превью, поиском и копированием ссылки.
- Загрузка защищена паролем длиной 25 символов. Смотреть сайты может кто угодно, а загружать — только тот, кто знает пароль. Неверных попыток — не больше 10 в минуту с одного IP.
- Удалить сайт можно из того браузера, из которого его загрузили (ключ удаления хранится в браузере). Администратор может удалить любой сайт, указав `ADMIN_TOKEN` в заголовке `X-Delete-Key`.
- Безопасность: загруженные сайты отдаются с заголовком `Content-Security-Policy: sandbox`, поэтому их скрипты работают, но не могут действовать от имени посетителя на самом архиве. Обход путей (`../`) блокируется.

## Запуск

Нужен Node.js 18+. Внешних зависимостей нет.

```bash
npm start          # http://localhost:3000
npm test           # смоук-тест
```

Через Docker:

```bash
docker build -t site-archive .
docker run -p 3000:3000 -v archive-data:/data site-archive
```

## Пароль на загрузку

- Задайте пароль переменной окружения `UPLOAD_PASSWORD`: ровно 25 символов, иначе сервер не запустится.
- Если переменная не задана, при первом запуске сервер сам придумает пароль, сохранит его в `DATA_DIR/upload-password.txt` и напечатает в лог.
- Сгенерировать подходящий пароль: `node -e "console.log(require('crypto').randomBytes(32).toString('base64url').slice(0,25))"`

## Настройки (переменные окружения)

| Переменная      | По умолчанию | Описание                                   |
|-----------------|--------------|--------------------------------------------|
| `PORT`          | `3000`       | Порт сервера                               |
| `DATA_DIR`      | `./data`     | Где хранятся загруженные сайты             |
| `MAX_UPLOAD_MB` | `50`         | Максимальный размер загружаемого файла     |
| `UPLOAD_PASSWORD` | генерируется | Пароль для загрузки, ровно 25 символов |
| `ADMIN_TOKEN`   | —            | Токен администратора для удаления любых сайтов |

## API

- `GET /api/sites` — список сайтов
- `POST /api/sites` — загрузка; тело запроса — сам файл, имя в заголовке `X-Filename`, пароль в `X-Upload-Password`, необязательные `X-Title` и `X-Description` (URL-кодированные)
- `DELETE /api/sites/:id` — удаление, ключ в заголовке `X-Delete-Key`
- `GET /s/:id/...` — просмотр сохранённого сайта

Пример загрузки из консоли:

```bash
curl -X POST --data-binary @page.html -H "X-Filename: page.html" -H "X-Upload-Password: ваш-пароль" http://localhost:3000/api/sites
```
